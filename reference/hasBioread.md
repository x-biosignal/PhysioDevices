# Is a BIOPAC (bioread) backend available?

Is a BIOPAC (bioread) backend available?

## Usage

``` r
hasBioread()
```

## Value

`TRUE` when the Python `bioread` module is reachable via reticulate.

## See also

[`readBIOPAC()`](https://x-biosignal.github.io/PhysioDevices/reference/readBIOPAC.md)

## Examples

``` r
hasBioread()
#> [1] FALSE
```
