# Is an Avro backend available?

Is an Avro backend available?

## Usage

``` r
hasAvroBackend()
```

## Value

`TRUE` when the Python `fastavro` module is reachable via reticulate.

## See also

[`readEmbracePlusAvro()`](https://x-biosignal.github.io/PhysioDevices/reference/readEmbracePlusAvro.md)
